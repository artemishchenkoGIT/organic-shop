# 🌿 Organic Shop

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen?style=for-the-badge&logo=github)](https://artemishchenkogit.github.io/organic-shop/)
[![Source Code](https://img.shields.io/badge/Source-Code-blue?style=for-the-badge&logo=github)](https://github.com/artemishchenkoGIT/organic-shop)

A responsive, user-friendly e-commerce website for an organic products store. The application is designed to showcase organic food items, present healthy categories, and provide visitors with an intuitive shopping experience and contact options.

## ✨ Features & Functionality

- **Responsive & Adaptive Layout:** Optimized for mobile, tablet, and desktop screens with a clean aesthetic.
- **Product Showcase & Categories:** Well-structured display of organic produce, benefits, and special offers.
- **Interactive UI Components:** Smooth navigation, interactive product cards, and user engagement elements.
- **Order & Contact Forms:** Convenient forms for user inquiries, newsletter subscriptions, and orders.
- **Cross-Browser Performance:** Fully tested and compatible across modern web browsers.

## 🚀 Getting Started Locally

To run and build this project locally, make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### 1. Clone the repository
```bash
git clone https://github.com/artemishchenkoGIT/organic-shop.git
```

### 2. Navigate to the project directory
```bash
cd organic-shop
```

### 3. Install dependencies
```bash
npm install
```

---

## 📜 Available Scripts

In the project directory, you can run the following commands:

### 🛠️ Development Mode
Runs the application in development mode with a local server and live-reloading:
```bash
npm run dev
```

### 📦 Production Build
Builds the app for production to the output folder (`dist` or `build`). It optimizes assets for performance and produces production-ready bundles:
```bash
npm run build
```
